Release check

  1. Four parts, in order: 1 set up the test copies, 2 test with fake data (the main test), 3 a short check with your real data, 4 release the new version. Everything runs on copies; your live sheet is only touched in part 4. A fifth part, Try to break it, is extra: Show → Try to break it, where you can also add tests of your own.
  2. Do the essentials before any school gets this version. The switch below shows only them; the optional checks can wait.
  3. For each check, do the steps, compare with "You should see", and mark it Works, Problem or Skip. For a Problem, write what you saw.
  4. Your answers save as you go, on any device that opens this page.
  5. When you're done, tell Claude "release check done": Claude reads your answers here. You can also copy the report or save it as a PDF at the bottom.
