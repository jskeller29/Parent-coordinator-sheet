Where to get it
    Option 1 — Upload the file (easiest)
    Pick the file you downloaded (CSV or Excel). Numbers come in exactly as they are in the file.
    Option 2 — Copy & paste
    1. Open the file you downloaded.
    2. Click any cell, then press Ctrl+A (Mac: ⌘+A) to select everything, including the top row.
    3. Press Ctrl+C (Mac: ⌘+C) to copy.
    4. Come back to the tab, click any cell, and paste values only: Ctrl+Shift+V (Mac: ⌘+Shift+V).
    ⚠️ If Excel shows numbers like 7.19E+09 or ####, widen the columns first: after Ctrl+A, double-click the line between any two column letters. Otherwise the real digits get lost.
